# 2026-07-23：生产级 Agent、算力扩张与行业平台

> 本页截至北京时间 2026 年 7 月 23 日整理。本次核验到的最新官方公告均标注为美国时间 7 月 22 日，重点关注 Agent 从演示走向生产所需的控制系统、算力基础设施和行业工作流。

## 今日焦点：OpenAI 推出企业 Agent 产品 Presence

OpenAI 发布 Presence，将其定位为面向企业客户的生产级 Agent 产品。Presence 支持语音和聊天场景，可回答问题、调用企业系统、执行经过批准的操作，并在需要时升级给人工处理。它不是单独的模型接口，而是把策略、标准操作流程、护栏、可执行动作、仿真评测和上线后的改进流程组合成一套部署系统。

每个 Agent 从一个明确岗位开始，只获得完成该岗位所需的知识和系统权限。企业负责定义允许执行的动作、审批条件和人工接管规则；上线后的真实会话、升级记录和质量信号用于发现缺口，Codex 可以提出改进建议，再由团队测试、批准并逐步发布。

OpenAI 披露，其英文电话支持渠道已经使用 Presence：公司称该 Agent 可在没有人工介入的情况下解决 75% 的来电问题，并在 10 天内把人工转接率降低了 15 个百分点。这是厂商提供的产品数据，仍需结合具体任务、样本范围和独立评测理解。

- [OpenAI 官方公告：Introducing OpenAI Presence](https://openai.com/index/introducing-openai-presence/)

**对 Agent 开发的启示**

1. 生产级 Agent 的核心不只是模型能力，而是权限、策略、审批、人工升级和版本控制组成的控制面。
2. 上线前评测与上线后观测必须连接起来；真实失败样本应进入可测试、可审批的持续改进流程。
3. 自动解决率不能单独代表质量，还需要同时监控误操作、错误升级、用户重试和政策合规率。

## 算力进展：AMD 与 Anthropic 扩大战略合作

AMD 与 Anthropic 宣布战略合作，计划部署最高 2 吉瓦的 AMD Instinct MI450 系列 GPU，首个 1 吉瓦部署预计从 2027 年上半年开始。方案基于 AMD Helios 机架级系统，包括 MI455X GPU、EPYC “Venice” CPU、Pensando 网络和 ROCm 软件。

双方还计划开展多年工程合作：使用 Claude 优化 AMD GPU 工作负载和 ROCm 开发，AMD 也将把 Claude 更广泛地用于工程和产品开发。AMD 同时承诺未来对 Anthropic 进行最高 50 亿美元的战略股权投资。部署规模、时间和投资均属于面向未来的计划，应与已经交付的能力区分开。

- [AMD 官方公告：AMD and Anthropic Announce Strategic Partnership](https://ir.amd.com/news-events/press-releases/detail/1292/amd-and-anthropic-announce-strategic-partnership-to-deploy-up-to-2-gigawatts-of-amd-instinct-mi450-series-gpus)

**对 Agent 开发的启示**：Agent 的长时程推理、并行执行和大规模在线服务最终受制于推理成本、吞吐与供应能力。模型公司主动扩展硬件来源，也说明软硬件协同和供应链多样化正在成为 Agent 平台竞争的一部分。

## 行业平台：Ushur 发布端到端客户旅程 Agent

Ushur 发布 Agentic Platform，面向保险、医疗和金融服务等受监管行业，将 Agent 用于从首次联系到最终解决的客户旅程。官方平台说明包含多步骤目标工作流编排、语音与文字渠道、知识层、文档处理，以及 Salesforce、ServiceNow 和遗留系统连接。

该产品把安全、合规和可审计性作为平台能力，而不只是部署后的补丁。对高监管场景而言，这种设计意味着 Agent 必须同时理解业务目标、系统状态和合规边界，不能只优化对话体验。

- [Ushur 发布公告：Ushur launches the Ushur Agentic Platform](https://www.globenewswire.com/news-release/2026/07/22/3331397/0/en/ushur-launches-the-ushur-agentic-platform-ai-agents-that-finish-the-job.html)
- [Ushur 官方平台说明：Ushur Agentic Platform](https://ushur.ai/platform)

## 可以立即实践的内容

为一个现有 Agent 画出最小控制面，并确保代码中能找到对应实现：

```text
用户目标
  -> 权限与策略检查
  -> 工具执行
  -> 结果验证
  -> 自动完成 / 请求审批 / 升级人工
  -> 日志与失败样本
  -> 测试后发布改进版本
```

然后增加三类评测：正常任务是否完成、越权操作是否被阻止、异常情况下是否正确升级人工。这比只测试最终回答是否“看起来合理”更接近生产 Agent 的真实要求。
