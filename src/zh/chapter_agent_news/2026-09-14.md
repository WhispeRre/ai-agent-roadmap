# 2026-09-14：托管 Agent、实时语音与自主攻击防线

> 本页于北京时间 **2026 年 9 月 14 日** 整理。OpenAI 开发者更新、Anthropic Newsroom 与 Google AI Blog 的最新可核验条目均发布于 **9 月 10 日**，9 月 11 日至 14 日未见这些官方索引新增公告。因此，本期回补此前因网络故障遗漏、且对 Agent 工程影响最大的三项进展。

## OpenAI：Agents API 进入公开测试

OpenAI 于 **2026 年 9 月 10 日**将 Agents API 发布为 public beta。官方将其定义为托管的 Codex harness：平台负责会话编排、上下文压缩与故障恢复；开发者可以用持久会话跨轮继续任务、流式返回进度，并连接自有工具与 MCP 服务器。任务既可运行在 OpenAI 托管沙箱，也可连接开发者自建或受支持供应商的沙箱。

- [OpenAI 官方 Changelog](https://developers.openai.com/changelog)
- [OpenAI 官方 Agents API 概览](https://developers.openai.com/api/docs/guides/agents-api/overview)

这意味着 Agent 平台的竞争边界正在从“模型调用”上移到“持久执行运行时”。落地时不要把 public beta 当作无条件生产承诺：应把会话 ID、压缩点、工具调用、沙箱来源和恢复次数写入追踪，并为状态导出、供应商切换与人工接管保留接口。

## OpenAI：GPT-Live 1 正式可用，语音与后端 Agent 可并行

同日，**GPT-Live 1** 在 API 中正式可用。官方说明其支持全双工语音会话：前台对话可以继续进行，同时由后端模型或 Agent 执行推理与工具调用；开发者可选择 Responses delegation，或通过 client delegation 接入自己的后端。语音会话按秒计费，标价为 **每分钟 0.05 美元**，后端模型与工具用量另行计费。

- [OpenAI 官方 Changelog](https://developers.openai.com/changelog)
- [OpenAI 官方 GPT-Live 指南](https://developers.openai.com/api/docs/guides/live)

语音 Agent 因此需要两条独立状态机：一条维护低延迟对话、打断与续说，另一条管理较慢的推理和工具任务。工程上应分别记录首音延迟、打断成功率、后端任务时延和合并账单，并明确后端结果过期、用户改口或工具失败时的取消与回滚规则。

## Anthropic：攻击者已把多 Agent 编排用于完整攻击链

Anthropic 于 **2026 年 9 月 10 日**发布 2026 年 9 月威胁情报报告，覆盖其在 **2025 年 12 月至 2026 年 8 月**间中断的活动，涉及网络攻击、影响行动、监控、诈骗、生物滥用、常规武器开发与非法蒸馏七类风险。报告称，多数网络行动中的 AI 已不只是回答问题，而是通过多 Agent 框架直接执行或编排侦察、利用和数据外传；人类主要负责设定目标并审阅外传结果。

- [Anthropic 官方报告：Detecting and countering misuse of AI: September 2026](https://www.anthropic.com/threat-intelligence-report-september-2026)

报告给防守方的关键信号是：不能只审计单次提示或单个工具。生产 Agent 应把任务分解、子 Agent 扇出、持久记忆、凭证读取、网络目标与数据外传视为同一条行为链；对高风险组合设置速率限制、短期凭证、目的地白名单、异常扇出检测和强制人工确认。

## 对 Agent 开发的直接影响

| 变化 | 新能力或新风险 | 建议立即加入的控制 |
| --- | --- | --- |
| 托管 Agents API | 持久会话、上下文压缩、恢复与沙箱成为平台能力 | 记录压缩点和恢复原因；保留状态导出与人工接管 |
| GPT-Live 1 | 语音对话可与后端推理、工具执行并行 | 分离前后台状态机；实现取消、过期与成本归因 |
| 自主攻击框架扩散 | 多 Agent 可覆盖侦察、利用、持久化和外传 | 关联审计整条行为链；限制凭证、网络与子 Agent 扇出 |
