# 2026-08-23：数据驻留、工具边界与内容溯源的复核

> 本页于北京时间 **2026 年 8 月 23 日 17:17** 核验。截至核验时，未发现可直接复验为 8 月 22 日或 8 月 23 日发布的官方 AI/Agent 公告；以下为“截至今天最新可核验的 AI/Agent 动态”。条目的原始发布时间与本次核验时间分开记录，不把较早公告写成今日发布。

## OpenAI：零数据保留与跨交互安全信号

OpenAI 于 **2026 年 8 月 19 日**发布 *Offering Zero Data Retention for frontier models*，介绍 Private Safety Processing 预览。符合条件的 API 客户启用 Zero Data Retention（ZDR）后，提示词和响应不会在请求处理后由 OpenAI 保留；Private Safety Processing 则尝试在不暴露客户内容的条件下识别跨交互风险模式。

- [OpenAI 官方原始公告：Offering Zero Data Retention for frontier models](https://openai.com/index/offering-zero-data-retention-for-frontier-models/)

这类设计把“数据最小化”和“长任务安全监控”放在同一运行契约中。Agent 产品需要明确数据驻留位置、客户密钥、可见风险信号、保留期限和申诉路径，不能把 ZDR 简化为完全没有安全观测。

## Google：Managed Agents 的工具调用策略边界

Google 于 **2026 年 7 月 28 日**发布 *Gemini API Managed Agents: 3.6 Flash, hooks, and more*。Managed Agents 在隔离云端沙盒中执行推理、代码、文件和网页工具，并提供 `pre_tool_execution` 与 `post_tool_execution` 环境钩子、预算控制和定时触发器。

- [Google 官方原始公告：Gemini API Managed Agents: 3.6 Flash, hooks, and more](https://blog.google/innovation-and-ai/technology/developers-tools/expanding-managed-agents-gemini-api-3-6-flash-hooks/)

钩子可在工具执行前阻断 `code_execution` 或 `write_file`，也可在执行后做检查。生产 Agent 应把匹配规则、决定、超时、失败语义、网络范围和凭据访问写入审计记录；提示词约束不能替代工具边界的强制策略。

## Anthropic：文本水印是概率性溯源信号

Anthropic 于 **2026 年 8 月 14 日**发布 *How Claude’s text watermark works*，说明 Claude 文本水印通过低风险词语选择留下可检测模式，用于判断 Claude 参与生成的可能性。短文本、事实性段落或轻量校对场景的检测能力较弱，水印不能证明唯一作者。

- [Anthropic 官方原始公告：How Claude’s text watermark works](https://www.anthropic.com/news/claude-text-watermark)

内容型 Agent 应将模型版本、提示来源、人工编辑和 C2PA 等信息与水印结果并列保存，并在界面和审计记录中区分“模型参与概率”与“作者/责任归属”，避免将概率信号过度解释为身份结论。
