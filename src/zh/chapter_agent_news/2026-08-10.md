## Google：Managed Agents 把钩子、预算和定时触发器带进托管沙盒

Google DeepMind 于 **2026 年 7 月 28 日**发布 *Gemini API Managed Agents: 3.6 Flash, hooks, and more*。官方说明，Gemini API Managed Agents 默认切换到 Gemini 3.6 Flash，并增加环境钩子、总 token 预算、定时触发器、环境管理 API 和免费层项目访问。钩子可在沙盒内每次工具调用前后运行脚本，用于阻断、lint 或审计；达到 `max_total_tokens` 后交互返回 `incomplete`，环境状态保留，可用 `previous_interaction_id` 继续。

- [Google 原始公告：Gemini API Managed Agents: 3.6 Flash, hooks, and more](https://blog.google/innovation-and-ai/technology/developers-tools/expanding-managed-agents-gemini-api-3-6-flash-hooks/)

这些是托管运行时的控制面能力，不等于任意账户、地区或模型入口都已开放。生产接入时应记录钩子版本、匹配到的工具、拒绝原因、预算耗尽状态、续跑 ID 和沙盒保留时长；免费层可用也不等于成本或配额没有上限。

## OpenAI：Astra 的关键网络能力仍是开发期评估，不是已发布模型能力

OpenAI 于 **2026 年 8 月 7 日**发布 *Responding to the next frontier of critical cyber capabilities*。公告称，对尚未发布的 Astra 的初步内部评估显示，不能排除 Preparedness Framework 的 Critical 网络能力阈值；OpenAI 同时说明 Astra 尚未发布，并提出隔离测试环境、限制网络和工具访问、权重保护、监控和沙盒执行等控制措施。

- [OpenAI 原始公告：Responding to the next frontier of critical cyber capabilities](https://openai.com/index/responding-next-frontier-critical-cyber-capabilities/)

“不能排除阈值”是风险评估结论，不是功能清单或可用性承诺。对具备代码执行、网络访问或凭据能力的 Agent，应把模型评测、工具权限、网络出口、监控告警和人工中断责任人一起验收；不要从 Astra 的开发期评估推断 GPT-5.6-Sol 或其他已发布模型具备同等能力。

## Anthropic：Fable 5 的生物安全分类器更新仍保留双用途回退

Anthropic 于 **2026 年 8 月 7 日**发布 *Improving Fable 5's biology safeguards*。官方称，通过重写分类器规则、专家反馈、训练数据更新和重新训练，Fable 5 在其测试中的生物相关回退约减少 **85%**；双用途病毒学、毒理学和分子设计等专业请求仍会回退至 Opus 5，Fable 不适用于专业生物研究和药物开发。

- [Anthropic 原始公告：Improving Fable 5's biology safeguards](https://www.anthropic.com/news/improving-fable-5-s-biology-safeguards)
- [Anthropic News](https://www.anthropic.com/news)

85% 是厂商测试中的路由结果，不能外推为所有提示、地区、账户或入口的固定比例。健康、生物等高影响工作流应实测拒答、回退和人工升级，并保留可审计的分类器与模型版本。
