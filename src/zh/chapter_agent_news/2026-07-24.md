# 2026-07-24：健康数据、经济指数与内容行业 AI

> 本页截至北京时间 2026 年 7 月 24 日整理。当前核验到的最新官方公告发布于美国时间 7 月 23 日和 22 日，重点关注敏感数据连接、可追溯的数据问答，以及 Agent 在内容行业中的实际工作流。

## 今日焦点：Health in ChatGPT 开始在美国上线

OpenAI 于 7 月 23 日发布 Health in ChatGPT，允许美国成年用户自愿连接 Apple Health 和受支持的医疗记录。连接后，ChatGPT 可以结合用药、化验结果、就诊记录、睡眠和活动数据，帮助用户比较历史变化、准备就诊问题或理解健康信息。

该功能面向美国地区已登录的 Free、Go、Plus 和 Pro 用户，在 Web 和 iOS 端逐步推出，目前不支持 Codex。OpenAI 强调它用于支持而非替代专业医疗服务，并承认模型仍可能出错，重要信息和医疗决策需要由合格医务人员复核。

### 数据与权限边界

- 连接的医疗记录、Apple Health 数据以及使用这些数据的对话，不用于训练基础模型或定向广告。
- 默认情况下，ChatGPT 在使用连接的健康信息前会请求许可；用户也可以改为持续授权。
- 断开数据源后，同步数据将在 30 天内从 OpenAI 系统删除，但已经进入对话历史的内容需要用户另行删除。
- 在其他插件中执行可能披露健康信息的动作时，系统会增加检查，部分敏感操作需要再次确认。

- [OpenAI 官方公告：Launching Health in ChatGPT](https://openai.com/index/health-in-chatgpt/)

**对 Agent 开发的启示**：一旦 Agent 能访问健康、财务或身份数据，连接能力本身不是最难的问题。更关键的是逐次授权、用途限制、删除语义、跨工具披露检查，以及在高风险决策中明确升级给专业人员。

## 数据连接：Claude 可直接查询 Anthropic Economic Index

Anthropic 于 7 月 22 日推出 Economic Index 连接器。用户可以在 Claude 的连接器目录启用它，通过自然语言查询职业、地区和任务层面的 AI 使用情况，并要求 Claude 展示底层数据。

这一功能把公开数据集从“下载后自行分析”变成了可追问的数据产品。例如，用户可以询问哪些职业使用 AI 最多、教师通常把 Claude 用于什么任务，或自动化任务在过去一年如何变化。

Anthropic 同时说明，Economic Index 反映的是 Claude 使用模式，并不等同于整个劳动力市场。因此，回答必须保留数据范围、样本偏差和适用边界，不能把平台内部使用数据直接外推为宏观经济事实。

- [Anthropic 官方公告：Ask Claude about the Anthropic Economic Index](https://www.anthropic.com/news/anthropic-economic-index-connector)
- [Anthropic Economic Index](https://www.anthropic.com/economic-index)

**对 Agent 开发的启示**：高质量数据 Agent 不应只给出流畅结论，还要能追溯来源、展示原始数据、解释样本边界，并在证据不足时降低结论强度。

## 行业实践：AI Agent 进入新闻生产与内容服务

OpenAI 于 7 月 22 日汇总了多家新闻机构的 AI 应用案例。报道、产品和商业团队正在把 AI 用于公共文件分析、事实核验、会议记录整理、翻译、内容检索和读者交互。

其中几类工作流与 Agent 设计直接相关：

- The Daily Beast 的 Data Scouts 在 Slack 中识别业务机会、解释数据并提出供人审核的下一步建议。
- The Atlantic 为互动悬疑游戏中的角色建立 Agent，让角色根据各自对话风格、动机和背景回应玩家。
- Future 正在构建结合 AI Agent、可配置工作流和编辑工具的内部平台。
- 多家媒体使用 AI 处理公共记录、会议文本或大型数据集，但保留记者和编辑对选题、事实与发布的最终判断。

- [OpenAI 官方案例汇总：How news organizations are using AI](https://openai.com/index/how-news-organizations-are-using-ai/)

这些案例来自技术供应商与合作机构的自述，适合观察使用模式，不应直接当作独立效果评估。真正需要验证的是节省了多少人工步骤、错误如何被发现、引用能否追溯，以及编辑责任是否清晰。

## 今日趋势判断

| 方向 | 最新信号 | 工程要求 |
| --- | --- | --- |
| AI 连接更敏感的个人数据 | ChatGPT 接入健康记录与可穿戴设备数据 | 逐次授权、最小化访问、删除机制、敏感操作确认 |
| 数据产品转向对话式查询 | Claude 直接查询 Economic Index | 来源追溯、样本说明、结果复现、避免过度外推 |
| Agent 嵌入行业现有工具 | 新闻机构在 Slack、编辑平台和读者产品中部署 Agent | 人工复核、角色责任、事实核验、工作流可观测性 |

## 可以立即实践的内容

为一个连接外部数据源的 Agent 增加以下响应结构：

```text
结论
  -> 使用了哪些数据
  -> 数据覆盖范围与更新时间
  -> 关键证据或原始记录
  -> 不确定性与不可外推部分
  -> 是否需要人工或专业人员确认
```

随后测试三种失败情形：用户撤销权限后数据是否仍被访问、数据缺失时是否编造结论、跨工具操作是否在披露敏感信息前请求确认。
